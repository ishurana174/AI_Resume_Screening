# 🤖 AI Resume Screening Tool

An intelligent AI-powered Resume Screening Tool that helps automate the recruitment process by analyzing resumes and matching them with job requirements. Built with Python and Flask, this project demonstrates the practical application of Artificial Intelligence in HR technology.

## 🚀 Features
- 📄 Upload PDF & DOCX resumes
- 🧠 AI-based resume analysis
- 📊 Resume scoring system
- 🎯 Job Description matching
- ⚡ Fast and user-friendly interface
- 💻 Responsive web application

## 🛠️ Tech Stack
- Python
- Flask
- HTML5
- CSS3
- JavaScript
- PyPDF2
- python-docx

## 📂 Project Structure
```
AI_Resume_Screening
├── src
├── resumes
├── output
├── templates
├── static
└── app.py
```

## ▶️ Installation

```bash
git clone https://github.com/ishurana174/AI_Resume_Screening.git
cd AI_Resume_Screening/src
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python3 app.py
```
